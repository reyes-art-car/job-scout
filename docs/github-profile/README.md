---

**En producción ahora mismo:** un CRM de prospección comercial para el
sector del juego, que diseño, desarrollo y mantengo en solitario desde
arquitectura hasta despliegue.

- API REST en Spring Boot protegida con JWT, refresh tokens y RBAC (Spring Security)
- Persistencia con Spring Data JPA / Hibernate, compatible con MySQL y PostgreSQL, arquitectura por capas y SOLID
- Cliente Angular + TypeScript responsive, integrado contra la API
- Importación/exportación en Excel y CSV
- CI/CD con GitHub Actions y Docker, desplegado en un VPS de IONOS; también empaquetado como APK Android
