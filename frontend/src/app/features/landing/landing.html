Antes de empezar

  • Las ofertas que verás son de ejemplo. Se puntúan con las tecnologías de tu CV, y puedes añadir las tuyas.
  • El CV se lee de forma automática y a veces se equivoca. Podrás revisarlo y corregirlo antes de guardar.
  • La búsqueda automática de ofertas con Claude Code solo funciona si instalas el proyecto en local.
